# Web Hub — правила для агентов

## Комментарии запрещены
- Не добавлять комментарии в код ни в каком виде (`//`, `#`, `/* */`, `<!-- -->`, docstring-комментарии с explanatory текстом).
- Исключение: код, требующий комментария по стандарту (например, shebang `#!/usr/bin/env sh`, прагмы, licencse-заголовок, если попросит владелец).
- Не удалять существующие комментарии, если это не запрошено.

## Git и репозиторий
- Remote: `git@github.com:Xhiveee/web-hub.git`
- Коммитить ТОЛЬКО по прямому запросу владельца. Без запроса — никаких commit/push/force-push/rebase.
- Никогда: `--force`, `git config` изменения, hook-skips, `--amend` после пуша, empty commits.
- Коммит-сообщение: Conventional Commits (`feat:`, `fix:`, `chore:`, `docs:`, `refactor:`), 1 строка, без точек.
- Не коммитить: `.env`, `data/`, `node_modules/`, `dist/`, `__pycache__/`, `*.tar.gz`, любые секреты и ключи.
- Игнорируй `data/` целиком: там база, файлы юзеров и ключи.
- Перед коммитом: `git status` + `git diff`, стейджить только нужное.
- Push только в `main` и только после явного запроса.
- Не создавать ветки, PR и issues без запроса.

## Архитектура
- Backend: FastAPI, `backend/app/`, SQLite в `data/hub.db`, файлы в `data/uploads/`.
- Frontend: React + Vite, `frontend/src/`, страницы в `frontend/src/pages/`.
- Деплой: docker-compose + Caddy. Установка строго в `/opt/hub/` через `install.sh`.
- Секреты через `.env` (генерирует `install.sh`). Никогда не хардкодить ключи.
- Стиль кода: без комментариев, лаконичный, существующие конвенции файла соблюдать.

## Прочее
- Данные пользователей личные и друзей: никогда не дампить их содержимое в логи, коммиты или ответы.
- Любые изменения после правок: собирать/проверять (`docker compose build` или минимум `vite build` + `py_compile`).
